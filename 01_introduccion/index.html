1. Introducción

1.1. Título del reto

Implementación de una Plataforma Web para la Gestión de Cursos de Cocina.

1.2. Contexto

Para una enseñanza acorde a nuestros tiempos ha empezado a ser imprescindible inclinarse más hacia la digitalización. En el sector de la gastronomía, la transición hacia modelos híbridos permite una gestión más eficiente de recursos, energías y espacio digital.

1.3. Problemática o necesidad

Actualmente existe un crecimiento notable en el consumo de comida preparada y servicios digitales. Sin embargo, muchas plataformas carecen de una infraestructura correctamente planificada. El despliegue de estas plataformas suele enfrentarse a problemas de seguridad de datos y una arquitectura deficiente, lo que provoca caídas o tiempos de carga excesivos.

1.4. Objetivos

Objetivo general Diseñar e implementar una infraestructura informática completa que soporte una plataforma web de gestión de cursos de cocina, previniendo errores típicos de seguridad, escalabilidad, disponibilidad y eficiencia.

Objetivos específicos - Configuración de un entorno de servidor basado en GNU/Linux. - Diseño de una topología de red segmentada mediante VLANs. - Implementación de un Sistema Gestor de Bases de Datos (SGBD) robusto. - Despliegue de servicios web con certificados de seguridad TLS/SSL. - Establecimiento de políticas de backup y recuperación.

1.5. Interesados

Interesado Relación con el proyecto Necesidad principal
Alumnos Consumidores de los cursos Plataforma rápida, responsiva para móviles y privacidad de sus datos personales.
Chefs / Cocineros Creadores de contenido Espacio asignado para subir material (cuotas de disco) y facilidad de uso.
Administrador / IT Mantenimiento del sistema Infraestructura robusta, monitorización de recursos y backups automáticos.
