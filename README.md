#  Plataforma Web para la Gestión de Cursos de Cocina

> **Proyecto Intermodular — 2.º Curso de ASIR (Administración de Sistemas Informáticos en Red)**  
> *I.E.S. Ribera del Tajo*

---

##  Descripción del Proyecto
Diseño e implementación de una infraestructura informática completa basada en **GNU/Linux (Ubuntu Server)** para dar soporte a una plataforma web de gestión de cursos de cocina. El proyecto abarca la segmentación de red mediante **VLANs**, la configuración de un servidor **LAMP (Linux, Apache, MySQL/MariaDB, PHP)**, la optimización de seguridad (UFW, Fail2Ban, TLS/SSL) y políticas de copias de seguridad automatizadas.

---

##  Tecnologías y Herramientas

* **Sistemas Operativos:** Ubuntu Server 22.04 LTS
* **Servidor Web:** Apache2 con certificados de seguridad TLS/SSL
* **Base de Datos:** MariaDB / MySQL
* **Redes y Seguridad:** Cisco Packet Tracer, VLANs (IEEE 802.1Q), UFW, Fail2Ban
* **Desarrollo Web:** HTML5, CSS3, JavaScript, PHP
* **Documentación & CI/CD:** Markdown, MkDocs, GitHub Actions, GitHub Pages
